# Simple Image Gallery Using HTML & CSS

## Project Overview

Simple Image Gallery is a static frontend website developed using HTML5 and CSS3. It displays a collection of 12 plant images with individual titles and descriptions in a structured gallery layout.

The project demonstrates the use of HTML elements and CSS Flexbox to create an organized image gallery.

## Features

- Displays 12 plant images.
- Individual titles and descriptions for each image.
- Responsive gallery layout using CSS Flexbox.
- Automatic wrapping of images into multiple rows.
- Simple and clean user interface.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- JPEG Images

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `css/index.html` in your web browser.
4. Explore the plant image gallery.
